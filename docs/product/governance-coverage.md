## Gaps, in one list
1. No ethics review forum (DP1, DP3, DP4).
2. No persisted participant id registry (DP2, ADR-004).
3. Access enforced by a build check, not by database roles (DP2, ADR-006).
4. No real deletion job that reaches raw data (DP5, ADR-017).
5. Every age-rule jurisdiction row is unverified and no legal review has happened (DP5, ADR-022).
6. No real consumer to log, so adoption is instrumented, not observed (all products; see `mart_goal_scorecard`).
